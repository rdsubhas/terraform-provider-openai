# OpenAI Terraform Provider Documentation

The generated provider documentation is organized into:

- [`index.md`](index.md): provider configuration and authentication
- [`resources/`](resources/): managed OpenAI resources
- [`data-sources/`](data-sources/): OpenAI data sources

For installation, development, migration, and support information, see the
[repository README](../README.md). For complete examples, see [`examples/`](../examples/).

Generated reference pages should not be edited by hand. Run `go generate ./...`
after changing provider schemas or examples and commit the resulting documentation.
